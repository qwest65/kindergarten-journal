# Kindergarten Journal

Веб-прототип электронного журнала занятий детского сада.

## Возможности прототипа

- Обзор занятий и посещаемости.
- Журнал занятий: дата, группа, тема, педагог, плановая и фактическая длительность, статус.
- Справочник групп и воспитанников.
- Отметки посещаемости по каждому занятию.
- Фильтрация журнала по группе, месяцу и статусу.
- Отчёты по занятиям, посещаемости и группам.
- Экспорт CSV с кодировкой UTF-8 BOM и разделителем `; ` для открытия в Excel.

## Текущий статус

Это **первый интерфейсный прототип**. Данные сохраняются в localStorage текущего браузера и не синхронизируются между сотрудниками. Используются вымышленные демонстрационные данные. Не вносите реальные ФИО воспитанников до подключения защищённого серверного хранения и авторизации.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **GitHub Actions**.
3. Workflow из `.github/workflows/pages.yml` опубликует `index.html`.
4. После успешного запуска адрес сайта появится в **Settings → Pages**.

Для приватного репозитория доступность GitHub Pages зависит от тарифа и настроек аккаунта/организации.

## Следующие этапы

- Подключить серверное хранилище для общей работы нескольких сотрудников.
- Добавить авторизацию и роли.
- Настроить резервное копирование и журнал изменений.
- Добавить настоящий XLSX-экспорт, если потребуется формат Excel с несколькими листами.

## Стек

- HTML, CSS, JavaScript без сборщика.
- GitHub Pages для статического интерфейса.
- localStorage только для демонстрации.
