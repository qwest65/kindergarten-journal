# Журнал детского сада

Онлайн-журнал посещаемости и занятий для детского сада. Работает целиком на GitHub, без серверов и оплаты.

Адрес сайта после публикации: **https://qwest65.github.io/kindergarten-journal/**

## Что умеет

- **Отметить.** Воспитатель выбирает группу и дату и отмечает каждого ребёнка: «Был», «Не был», «Болеет», «Отпуск» или «Уважительная причина». Кнопка «Отметить остальных „Был“» заполняет оставшихся одним нажатием.
- **Табель.** Таблица за месяц по группе с итогами и процентом посещаемости. Выгружается в Excel (.xlsx): лист «Сводка», отдельный лист на каждую группу и лист «Занятия».
- **Занятия.** Журнал занятий: дата, группа, тема, педагог, длительность, статус. Число присутствовавших детей подставляется из отметок.
- **Статистика.** Посещаемость по группам и по детям за месяц.
- **Журнал действий** (видят администратор и заведующая). Записывает, кто, когда и что сделал, включая исправления отметок («Петрова А.: Был → Не был»). Выгружается в Excel.
- **Управление**:
  - группы и дети (администратор и заведующая);
  - сотрудники: логины, пароли, назначенные группы (только администратор);
  - замена ключа GitHub (только администратор).

Роли:
- **Администратор** видит и меняет всё, включая сотрудников и ключ GitHub.
- **Заведующая** видит все группы, журнал действий и выгрузки, ведёт список детей и групп. Сотрудниками и ключом не управляет.
- **Воспитатель** работает только со своими группами и не видит раздел «Управление».

## Как устроено

| Где | Что лежит | Видимость |
|---|---|---|
| `qwest65/kindergarten-journal` | код сайта и `auth/users.json` (зашифрованные ключи доступа) | публичный |
| `qwest65/kindergarten-journal-data` | дети, группы, отметки, занятия, журнал действий | **приватный** |

- **Вход.** У каждого сотрудника свой логин и пароль. Ключ доступа GitHub зашифрован паролем сотрудника (PBKDF2, 600 000 итераций, AES-256-GCM) и расшифровывается только в браузере. В публичном репозитории нет ни имён, ни логинов в открытом виде, ни самого ключа.
- **Сохранение.** Каждое сохранение — это один коммит в приватный репозиторий вместе с записью в журнал действий. Полная история изменений хранится в GitHub, любую версию можно восстановить.
- **Одновременная работа.** Если два воспитателя сохраняют одновременно, сайт сам перечитывает данные и объединяет изменения.

## Первоначальная настройка (один раз)

### 1. Создать приватный репозиторий для данных

1. Откройте https://github.com/new.
2. В поле **Repository name** введите `kindergarten-journal-data`.
3. Выберите **Private**.
4. Поставьте галочку **Add a README file**.
5. Нажмите **Create repository**.

### 2. Включить публикацию сайта

1. В репозитории `kindergarten-journal` откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Через 1–2 минуты сайт откроется по адресу https://qwest65.github.io/kindergarten-journal/.

### 3. Создать ключ доступа (токен)

1. Откройте https://github.com/settings/personal-access-tokens/new.
2. **Token name**: `Журнал детского сада`.
3. **Expiration**: максимальный срок. За неделю до окончания GitHub пришлёт письмо, тогда ключ нужно заменить (см. ниже).
4. **Repository access** → **Only select repositories** → выберите оба репозитория: `kindergarten-journal` и `kindergarten-journal-data`.
5. **Permissions → Repository permissions → Contents** → **Read and write**.
6. Нажмите **Generate token** и скопируйте ключ (начинается с `github_pat_`). Больше его не покажут.

### 4. Первый вход

1. Откройте сайт. Появится экран «Первоначальная настройка».
2. Вставьте ключ, придумайте свой логин и пароль администратора (не короче 10 символов) и нажмите «Сохранить и войти».
3. В разделе **Управление** создайте группы и добавьте детей. Можно добавить сразу списком: каждый ребёнок с новой строки.
4. На вкладке **Сотрудники** добавьте заведующую (роль «Заведующая») и воспитателей. Сайт придумает пароль и покажет его один раз — передайте его сотруднику лично.

## Частые вопросы

**Сотрудник забыл пароль.**
Управление → Сотрудники → «Новый пароль».

**Администратор забыл пароль.**
На экране входа нажмите «Восстановить доступ администратора». Понадобится ключ GitHub. Можно создать новый, как в шаге 3.

**Сотрудник уволился.**
Управление → Сотрудники → «Изменить» → снимите галочку «Доступ разрешён». Чтобы гарантированно закрыть доступ, замените ключ GitHub (следующий пункт).

**Ключ GitHub истекает или мог попасть к посторонним.**
1. Создайте новый ключ (шаг 3).
2. Управление → Ключ GitHub → «Заменить ключ». Ваш пароль сохранится, остальным сотрудникам будут показаны новые пароли.
3. Удалите старый ключ на https://github.com/settings/personal-access-tokens.

**Новый пароль не срабатывает сразу.**
GitHub обновляет файл с паролями в течение 1–2 минут.

## Важно о безопасности

- Пароли должны быть длинными, не короче 10 символов. Код сайта публичный, поэтому короткий пароль можно подобрать перебором.
- Галочку «Запомнить на этом устройстве» ставьте только на личном или рабочем устройстве, к которому нет доступа у посторонних.
- Ограничения по ролям работают на уровне сайта. Технически подкованный сотрудник со своим паролем может получить ключ и прочитать все данные. Для детского сада обычно этого достаточно; при увольнении меняйте ключ.
- Можно вносить детей в сокращённом виде («Иванов М.»).

- Библиотека SheetJS загружается с cdnjs только при выгрузке в Excel.
- Настройки (`CONFIG`) находятся в начале `app.js`.
- Данные в приватном репозитории:
  - `data/users.json`, `data/groups.json`, `data/children.json`;
  - `data/attendance/ГГГГ-ММ.json`, `data/lessons/ГГГГ-ММ.json`, `data/log/ГГГГ-ММ.json`.
